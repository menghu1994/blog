# AI 推荐

AI 推荐不能只看“谁最强”。真实选择要同时看需求、价格、配额、地区、付款方式、稳定性、隐私和你自己的使用频率。

本文按小白视角给出购买建议。价格和配额变化很快，下面的判断适合作为选择逻辑，具体金额以官网为准。

## 先判断你是哪类用户

| 用户类型 | 推荐方向 | 不建议 |
| --- | --- | --- |
| 偶尔问问题 | 免费版或低价套餐 | 一上来买多个高阶套餐 |
| 学习和写作 | ChatGPT / Claude / Gemini 任选一个主力 | 为了排行榜频繁换工具 |
| 经常查资料 | Perplexity、Kimi、秘塔等搜索型 AI | 只用普通聊天模型硬查 |
| 程序员 | Cursor / GitHub Copilot / Claude Code / Codex CLI | 只靠网页聊天复制代码 |
| 重度代码 Agent 用户 | Claude Max、Cursor Pro+ / Ultra、ChatGPT Pro、Codex | 低配套餐硬跑长任务 |
| 视频图片创作 | Gemini / Sora / Midjourney / 即梦 / 可灵 | 用纯文本模型做视觉任务 |
| 公司团队 | Team / Business / Enterprise | 用个人账号共享给多人 |

## 通用聊天 AI

### ChatGPT

适合：综合能力、写作、学习、代码、图片、语音、数据分析、Agent 工作流。

优点：

1. 综合能力均衡，生态完整。
2. 工具多，适合从小白到进阶用户。
3. 适合“一个 AI 解决大多数问题”的用户。

注意：

1. 高级模型和深度能力通常有配额。
2. Pro 类高价套餐更适合重度用户，不适合偶尔使用。
3. API 和 ChatGPT 会员是两套计费体系，不要混淆。

推荐：

1. 新手先用免费版或 Plus。
2. 每天深度使用、经常撞配额，再考虑 Pro。
3. 团队协作、公司资料、统一管理，考虑 Business / Enterprise。

### Claude

适合：长文写作、代码理解、需求分析、文档整理、长上下文任务。

优点：

1. 文字表达和长文处理体验好。
2. 适合读文档、改文章、理解复杂代码。
3. Claude Code 对程序员很有价值。

注意：

1. 高阶套餐主要买的是更多容量和更高限制。
2. 如果你的任务很短、很简单，Pro 或 Max 不一定划算。

推荐：

1. 写作、文档、代码解释多，可以把 Claude 作为主力。
2. 经常使用 Claude Code，再考虑 Max。
3. 不确定前先用 Pro，不要直接冲最高档。

### Gemini

适合：Google 生态、长上下文、资料整理、NotebookLM、图片视频能力。

优点：

1. 和 Google 产品结合更自然。
2. 适合使用 Gmail、Drive、Docs、NotebookLM 的用户。
3. 高阶套餐更偏向多媒体和 Google AI 生态。

注意：

1. 如果你不在 Google 生态里，高价套餐价值会下降。
2. 不同地区功能和价格可能不同。

推荐：

1. 学习、资料整理、Google Drive 用户可以优先试 Gemini。
2. 视频生成、NotebookLM、Google 生态重度用户再考虑高阶。

## 搜索型 AI

搜索型 AI 的重点不是“更会聊天”，而是能快速查资料、给来源、整理结论。

代表：Perplexity、Kimi、秘塔、Google AI 搜索、ChatGPT/Claude/Gemini 的联网和研究模式。

适合：

1. 查最新新闻、政策、价格、软件版本。
2. 做竞品分析、资料收集、论文初筛。
3. 需要引用来源的文章。

推荐：

1. 查资料频繁：准备一个搜索型 AI。
2. 查资料不频繁：直接用主力聊天 AI 的联网功能。
3. 写文章前：先搜索型 AI 收集材料，再让写作型 AI 重组表达。

## 编程 AI

### Cursor

适合：想在编辑器里完成代码补全、问答、改文件、跑 Agent 的开发者。

优点：

1. 上手简单，像加强版 VS Code。
2. Agent、Tab 补全、项目索引体验完整。
3. 可以接多家模型。

注意：

1. 价格和用量强相关，重度 Agent 用户更容易消耗额度。
2. 官方建议日常 Agent 用户选 Pro+，重度用户选 Ultra。

推荐：

1. 新手程序员：先试免费或 Pro。
2. 每天都让 Agent 改项目：考虑 Pro+。
3. 高强度商业开发：再看 Ultra 或团队方案。

### GitHub Copilot

适合：已经使用 VS Code、JetBrains、GitHub 的开发者。

优点：

1. 补全和聊天集成成熟。
2. 适合日常写代码、解释代码、生成测试。
3. 对 GitHub 工作流友好。

注意：

1. 高级模型、Agent、代码审查、CLI 等会消耗 premium requests。
2. 免费版适合体验，不适合长期重度开发。

推荐：

1. 主要想要补全：Copilot 很合适。
2. 主要想让 AI 大范围改项目：Cursor、Claude Code、Codex CLI 也要比较。

### Claude Code / Codex CLI / Gemini CLI

适合：愿意在命令行里工作的开发者。

优点：

1. 能直接读项目、改文件、跑命令。
2. 更适合真实工程任务，不只是补全一两行。
3. 对 Bug 修复、重构、测试很方便。

注意：

1. 需要理解命令行和权限。
2. 不要在没备份、没 Git 的项目里让 Agent 大范围修改。

推荐：

1. 小白先从 IDE 插件开始。
2. 会 Git、会命令行后，再用 CLI Agent。
3. 重要项目先开分支，再让 AI 改。

## 小龙虾 / OpenClaw 类本地 Agent

这类工具更像“本地 AI 助理平台”，不是单纯聊天工具。它通常会接入你的电脑、消息渠道、日历、文件、脚本和多个模型。

适合：

1. 想让 AI 在本地 24 小时执行任务。
2. 想接飞书、钉钉、企业微信、QQ、Telegram 等消息入口。
3. 想组合不同模型和插件。
4. 想做个人自动化工作流。

注意：

1. 权限风险更高：它可能接触本地文件、账号和系统操作。
2. 安装渠道要谨慎，只从可信官网或开源仓库下载。
3. 不要把 API Key、公司机密、支付权限随便交给自动化 Agent。

推荐：

1. 小白先使用云端聊天 AI 和 IDE 插件。
2. 明确有自动化需求，再折腾小龙虾类工具。
3. 安装后先只给最小权限，测试稳定后再扩大权限。

## 怎么组合最划算

### 预算 0 元

1. ChatGPT / Claude / Gemini 免费版任选。
2. Kimi / 秘塔等免费搜索。
3. GitHub Copilot Free 或 Cursor Free 体验代码能力。

适合：学生、偶尔使用、刚入门。

### 预算约 20 美元/月

1. 选一个主力通用 AI：ChatGPT Plus、Claude Pro、Gemini AI Pro 三选一。
2. 搜索需求用免费搜索型 AI 补足。
3. 程序员可把预算换成 Cursor Pro 或 Copilot Pro。

适合：大多数个人用户。

### 预算约 40-80 美元/月

1. 一个通用 AI。
2. 一个编程 AI 或搜索型 AI。
3. 按实际高频任务补工具，不要平均撒钱。

适合：自媒体、开发者、研究生、自由职业者。

### 预算 100 美元/月以上

1. 主力通用 AI 高阶套餐。
2. 编程 Agent 高阶套餐。
3. 需要查资料再加搜索型 AI。

适合：每天靠 AI 产出工作成果的人。

## 排行榜怎么看

AI 会有能力排行、市场排行、使用排行，但它们只能回答不同问题。

| 排行类型 | 说明 | 局限 |
| --- | --- | --- |
| 能力榜 | 哪个模型在测试集上分高 | 不代表适合你的场景 |
| 使用榜 | 哪个产品用户多 | 用户多不等于最好 |
| 市场榜 | 公司收入、份额、增长 | 反映商业成功，不等于个人体验 |
| 编程榜 | 代码题、Agent 任务表现 | 不一定适合中文写作或搜索 |
| 价格榜 | 单位 token 或套餐价格 | 便宜不代表总成本低 |

小白最实用的测试方法：拿自己真实任务测 10 次。比如让它改一篇文章、解释一个报错、整理一份资料、写一个小功能。哪个工具让你少返工，哪个就更适合你。

## 最终建议

1. 第一个 AI：选 ChatGPT、Claude、Gemini 中你用得最顺手的一个。
2. 经常查资料：加搜索型 AI。
3. 经常写代码：加 Cursor、Copilot、Claude Code 或 Codex CLI。
4. 经常自动化：再研究 OpenClaw / 小龙虾。
5. 经常撞配额：再升级，不要提前为“可能会用”付费。
